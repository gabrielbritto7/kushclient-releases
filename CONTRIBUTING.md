# Contribuições e publicação

Este repositório distribui instaladores do KushClient. Alterações no launcher ou no KUSHMOD devem ser feitas no repositório de código correspondente; aqui ficam a documentação de distribuição e os arquivos das versões publicadas.

## Registrar uma melhoria

1. Descreva o problema ou objetivo e implemente uma alteração útil.
2. Verifique o comportamento afetado e registre o resultado.
3. Crie um commit com uma mensagem que explique a mudança.
4. Atualize a documentação e o changelog quando o comportamento visível mudar.

Agrupe alterações relacionadas em um commit coerente. Use as datas reais do trabalho e mantenha a atribuição dos autores, inclusive quando houver assistência de ferramentas.

## Preparar uma versão

Use um número de versão único e consistente no instalador e nas notas. Disponibilize o instalador em Assets da release correspondente e identifique requisitos e compatibilidade no texto da publicação.

Escreva o changelog com uma mudança por linha, sem etiquetas entre colchetes. Um exemplo de formato é:

```text
Adicionado convite para entrar no mundo de um amigo.
Corrigido o aviso exibido ao selecionar uma versão incompatível.
```

As linhas acima são exemplos de escrita, não um histórico de funcionalidades desta release.

## Mostrar o resultado

Quando uma alteração afetar a interface, inclua capturas reais da versão correspondente. Identifique dados de demonstração e diferencie um teste em servidor local de uma conexão validada pela internet.

Nas alterações concluídas entre 06:00 e 15:00, no horário de Brasília, as capturas acompanham a entrega e o changelog.

## Publicar material adequado ao projeto

Transforme decisões técnicas em documentação, exemplos ou melhorias reutilizáveis. Conversas privadas, credenciais e dados de terceiros ficam fora dos arquivos publicados. Material de outro projeto deve ir para seu próprio repositório.

Código e recursos de terceiros mantêm suas licenças e atribuições. A disponibilidade de um arquivo em uma conversa não define, por si só, uma licença para redistribuição.
