# KushClient — versões para Windows

Repositório de distribuição dos instaladores do KushClient.

## Baixar

Abra a página de [Releases](https://github.com/gabrielbritto7/kushclient-releases/releases) e consulte os arquivos em **Assets** da versão desejada. Leia as notas da versão antes de instalar.

Os links **Source code (zip)** e **Source code (tar.gz)** gerados pelo GitHub contêm os arquivos deste repositório; para instalar o launcher, escolha o instalador disponibilizado em Assets.

## Relatar um problema

Abra uma [issue](https://github.com/gabrielbritto7/kushclient-releases/issues/new) informando:

- Versão do KushClient e do Windows.
- Etapas para reproduzir o problema e o resultado esperado.
- Mensagem de erro e captura de tela, quando disponíveis.
- Versão do Minecraft e carregador de mods, se o problema ocorrer ao iniciar o jogo.

Ao anexar logs ou imagens, remova dados de acesso e informações pessoais.

## Desenvolvimento e histórico

Melhorias de código, documentação e correções devem registrar o que mudou e como a alteração foi verificada. Consulte o [guia de contribuição e publicação](CONTRIBUTING.md).

O changelog do launcher usa uma mudança por linha, sem etiquetas entre colchetes.
